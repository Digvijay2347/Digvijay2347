# Hi, I'm Digvijay 👋

**Robotics and AI Engineer | Simulation, Perception, Manipulation and Autonomy**

I build robotics systems across the stack: simulation and digital twins, perception, mobile robot autonomy, robotic arm manipulation, and learning-based control. I work with the **NVIDIA Omniverse ecosystem (Isaac Sim, Isaac Lab)** and **ROS 2**, and I use Python and PyTorch for the ML side.

- 🦾 **Manipulation:** pick-and-place workflows on **Universal Robots (UR) arms**, with RL policies trained in Isaac Lab
- 🚗 **Mobile robots:** AGV autonomy, including **obstacle detection, lane detection and lane following**
- 👁️ **Perception:** building and integrating perception stacks (camera-based detection, sensor pipelines)
- 🧠 **Foundation models for robots:** hands-on with **Gemini Robotics** models for vision-language robot control
- 🏗️ **Simulation:** digital twins and training environments in **Isaac Sim, Isaac Lab and MuJoCo**
- 🔌 **Middleware:** **ROS 2** nodes, topics, services, actions, tf2, Nav2 and MoveIt-style workflows
- 🧰 **Background:** full-stack web development (MERN), useful for dashboards and tooling around robot systems
- 📫 **Open to:** robotics, autonomy, perception and robot learning roles, and open-source collaboration

> Note: my professional work is proprietary, so the repositories here are personal projects built on open-source assets.
